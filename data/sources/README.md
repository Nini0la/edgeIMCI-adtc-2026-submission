# Clinical source

The authoritative source for this benchmark is **WHO — Integrated Management of Childhood Illness, Chart Booklet, March 2014** (ISBN 978 92 4 150682 3).

The WHO PDF is not redistributed with EdgeIMCI. Obtain it separately from WHO and place the unmodified file at:

```text
data/sources/IMCI chartbooklet 2014.pdf
```

Local PDF files in this directory are gitignored. Every encoded rule records the source section, `source_pdf_page` from the PDF viewer, and `source_printed_page` shown by the publisher.
