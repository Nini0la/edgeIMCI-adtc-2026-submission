# Historical selected-v0 rendering experiment

This directory preserves outputs from the original 14-case selected-v0 rendering experiment. It is historical evidence, not a current teacher-selection result.

The embedded `data/golden/...` path and original source hash in `summary.json` record the repository layout and bytes at the time of that run. The source has since been reclassified and moved to `data/archive/selected_v0/`; its current lifecycle restrictions are canonical in `data/archive/selected_v0/archive_manifest.json`.

Do not use these candidates or this summary for training, product evaluation, holistic generation, or current teacher selection.
